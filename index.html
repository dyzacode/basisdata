BASIS DATA

Database Management System

Mengenal konsep, komponen, fungsi, dan pengelolaan database.

🗄️
01 / PENGENALAN

Apa Itu Basis Data?

Basis data atau database adalah kumpulan data yang disimpan secara terstruktur di dalam komputer sehingga mudah diakses, dikelola, dicari, dan diperbarui.

Contoh Basis Data

  • Database data siswa sekolah.
  • Database nilai dan absensi.
  • Database pelanggan toko online.
  • Database transaksi perbankan.
💡 Contoh: Ketika sekolah menyimpan seluruh data siswa di komputer, sekolah sedang menggunakan sistem basis data.
02 / TUJUAN

Tujuan dan Manfaat Basis Data

📁 Penyimpanan

Menyimpan data secara terorganisir.

🔎 Pencarian

Mempermudah pencarian informasi.

🔒 Keamanan

Membantu menjaga data dari akses tidak sah.

⚡ Efisiensi

Mempercepat proses pengolahan data.

03 / KOMPONEN

Komponen Basis Data

1. Hardware

Perangkat keras seperti komputer dan server.

2. Software

Program pengelola database seperti MySQL.

3. Data

Informasi yang disimpan di dalam database.

4. Brainware

Manusia yang menggunakan sistem database.

5. Prosedur

Aturan dan langkah untuk mengelola database.

04 / STRUKTUR DATABASE

Tabel, Field, dan Record

Perhatikan contoh tabel data siswa berikut:

ID Nama Kelas Jurusan
001 Andi XII RPL
002 Budi XII TKJ
003 Siti XII DKV

Tabel: Keseluruhan kumpulan data siswa.

Field: Kolom ID, Nama, Kelas, dan Jurusan.

Record: Satu baris data siswa.

05 / KUNCI DATABASE

Primary Key dan Foreign Key

🔑 Primary Key

Field yang menjadi identitas unik setiap record dalam tabel.

Contoh: ID_Siswa.

🔗 Foreign Key

Field yang menghubungkan suatu tabel dengan tabel lainnya.

Contoh: ID_Kelas dalam tabel siswa.

06 / JENIS DATABASE

Jenis-Jenis Database

Relasional

Data disimpan dalam bentuk tabel.

Contoh: MySQL, PostgreSQL.

NoSQL

Data disimpan dengan struktur fleksibel.

Contoh: MongoDB.

Hierarkis

Data disusun dalam bentuk pohon.

Jaringan

Data dapat memiliki hubungan kompleks.

07 / SQL

Mengenal SQL

SQL (Structured Query Language) merupakan bahasa yang digunakan untuk mengelola dan mengakses database relasional.

-- Menampilkan data SELECT * FROM siswa; -- Menambahkan data INSERT INTO siswa (id, nama) VALUES (4, 'Dina'); -- Mengubah data UPDATE siswa SET nama = 'Rina' WHERE id = 4;
💡 SELECT digunakan untuk mengambil atau menampilkan data dari tabel.
08 / KESIMPULAN

Kesimpulan Pembelajaran

✓ Basis data adalah kumpulan data terstruktur.

✓ Database mempermudah penyimpanan data.

✓ Tabel terdiri dari field dan record.

✓ Primary Key mengidentifikasi record secara unik.

✓ Foreign Key menghubungkan tabel.

✓ SQL digunakan untuk mengelola database relasional.
