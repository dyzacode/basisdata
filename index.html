BASIS DATA

Database Management System

Mengenal konsep, komponen, fungsi, dan pengelolaan database dalam dunia teknologi.

🗄️
01 / PENGENALAN

Apa Itu Basis Data?

Basis data (database) adalah kumpulan data yang disimpan secara terstruktur di dalam komputer sehingga mudah diakses, dikelola, dicari, dan diperbarui.

Contoh dalam kehidupan sehari-hari

  • Database data siswa di sekolah.
  • Database nilai dan absensi siswa.
  • Database pelanggan toko online.
  • Database transaksi perbankan.
💡 Tahukah kamu?

Ketika sekolah menyimpan data seluruh siswa dalam komputer, sekolah tersebut sedang menggunakan konsep basis data.

02 / TUJUAN

Tujuan dan Manfaat Basis Data

📁 Penyimpanan

Menyimpan data secara terorganisir.

🔎 Pencarian

Mempermudah pencarian informasi.

🔒 Keamanan

Membantu melindungi data dari akses tidak sah.

⚡ Efisiensi

Mempercepat pengolahan data.

03 / KOMPONEN

Komponen Basis Data

Dalam sebuah sistem basis data terdapat beberapa komponen penting:

1. Hardware

Perangkat keras seperti komputer dan server.

2. Software

Program untuk mengelola database, seperti MySQL.

3. Data

Informasi yang disimpan dalam database.

4. Brainware

Manusia yang menggunakan dan mengelola database.

5. Database Administrator

Orang yang bertanggung jawab mengelola database.

04 / STRUKTUR DATA

Tabel, Field, dan Record

Ketiga istilah ini merupakan bagian penting dalam database relasional.

ID Nama Kelas Jurusan
001 Andi XII RPL
002 Budi XII TKJ
003 Siti XII DKV

Tabel: Keseluruhan kumpulan data siswa.

Field: Kolom ID, Nama, Kelas, dan Jurusan.

Record: Satu baris data siswa.

05 / KUNCI DATABASE

Primary Key dan Foreign Key

🔑 Primary Key

Field yang digunakan sebagai identitas unik setiap record dalam sebuah tabel.

Contoh: NIS atau ID_Siswa.

🔗 Foreign Key

Field yang menghubungkan suatu tabel dengan tabel lainnya melalui primary key.

Contoh: ID_Kelas pada tabel siswa.

06 / JENIS DATABASE

Jenis-Jenis Database

Relasional

Menyimpan data dalam bentuk tabel.

Contoh: MySQL, PostgreSQL.

NoSQL

Menyimpan data dengan struktur yang fleksibel.

Contoh: MongoDB.

Hierarkis

Mengorganisasi data dalam bentuk pohon.

Jaringan

Memungkinkan hubungan data yang lebih kompleks.

07 / SQL

Mengenal SQL

SQL (Structured Query Language) adalah bahasa yang digunakan untuk mengelola dan mengakses database relasional.

-- Menampilkan semua data siswa

SELECT * FROM siswa;

-- Menambahkan data siswa

INSERT INTO siswa (id, nama) VALUES (4, 'Dina');

-- Mengubah nama siswa

UPDATE siswa SET nama = 'Rina' WHERE id = 4;
💡 SELECT digunakan untuk mengambil atau menampilkan data.
08 / KESIMPULAN

Kesimpulan Pembelajaran

✓ Basis data merupakan kumpulan data terstruktur.

✓ Database mempermudah penyimpanan dan pengolahan data.

✓ Tabel terdiri dari field dan record.

✓ Primary Key dan Foreign Key membantu menghubungkan data.

✓ SQL digunakan untuk mengelola database relasional.
